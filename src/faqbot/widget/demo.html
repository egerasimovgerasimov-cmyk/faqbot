Python · no ML · runs offline

Answers, not hallucinations.

faqbot matches a visitor's question against your own knowledge base. No API keys, no vector database, no data leaving your server — just a small, testable engine you can read in one sitting.

Ask the demo bot Open API docs

Understands Russian morphology

Light stemming and synonyms keep «путёвка», «путёвки» and «путёвок» together. English works too.

Admits uncertainty

Low confidence triggers a fallback with related topics, not a random answer.

Asks before guessing

Two close matches produce a clarifying question with clickable options.

Remembers the thread

Follow-ups like «а сколько дней?» reuse the previous question for context.

One file is the whole knowledge base

bot:
  name: Солнышко
  greeting: Привет! Спросите про путёвки и смены.
  fallback: Не нашёл ответа — напишите оператору.
  threshold: 0.45

synonyms:
  - "путёвка = тур, поездка, путевка"

qa:
  - question: Сколько стоит путёвка?
    answer: От 42 000 до 58 000 ₽ за 14 дней.
    keywords: цена стоимость
    category: Путёвки
    priority: 10

Run it

pip install -e ".[api]"
faqbot --kb examples/camp/kb.yaml serve --port 8000

Then open http://127.0.0.1:8000 and ask «сколько стоит путёвка», «а сколько дней?» or «какие документы нужны».
